# Git & GitHub Basics

A hands-on repository for learning and practising Git and GitHub fundamentals, including version control, file management, commits, and repository workflows.

## 📚 Topics Covered

- Introduction to Git and version control
- Creating and managing repositories
- Tracking changes in files
- Staging and committing changes
- Understanding `.gitignore`
- Working with files and folders
- Basic GitHub repository management

## 💻 Common Git Commands

| Command | Purpose |
|---|---|
| `git init` | Initialize a Git repository |
| `git status` | Check repository status |
| `git add .` | Stage changes |
| `git commit -m "message"` | Save changes in a commit |
| `git log` | View commit history |
| `git push` | Upload commits to GitHub |
| `git pull` | Retrieve remote changes |
| `git clone` | Copy a remote repository |

## 📂 Repository Contents

This repository contains sample text files, a `.gitignore` file, and a public folder used for practising basic Git operations.

## 🎯 Purpose

To build a practical understanding of version control and become comfortable using Git and GitHub in software development workflows.
